## Notes

- First-depositor share-inflation (V-06) does not apply to this protocol: `protocol-type-specialist` determined
  `BasketVault` has no floating share price for a griefer to inflate against (`mint` requires the caller's own
  legs to fully deliver `requiredShares`, independent of existing vault slack — B1a/Audit F-1). No V-06 property
  was generated; this is a documented N/A, not a dropped property.
- `VS-01`'s wording ("ratio never zero") and `VT-06`'s window-anchor mechanism check are related but distinct:
  VS-01 (GL-29) is implementable today; VT-06 (GL-28) needs a new StockRegistry view and is marked `[-]` in
  PROPERTIES.md.
- Several GLOBAL properties reference functions not currently reachable by any handler
  (`addRepresentation`/`setUnderlying`/`createBasket` — GL-20, GL-27, GL-09's `everCreatedBaskets` half). They are
  still valid, testable-in-principle guarantees and kept in the plan; they will not find new bugs until a handler
  exercises those entry points mid-run. Flagged per-row above.
